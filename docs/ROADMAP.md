- [x] Python standard-library loopback launcher with compiler smoke check.
- [x] Linux shell launcher and initial Windows batch launcher.

## Later worlds

Adapt existing lessons rather than inventing incompatible replacements: Mapping Uncertainty for linked lists, The Last Door Home for stacks, and the railway continuation for queues. Trees and graphs follow later. Use docs/STORY_BIBLE.md to distinguish binding decisions from campaign proposals.

## Decision log · 2 October 2026

Distribution is local-first: GitHub source/downloads; each player’s Python/GCC runtime. Earlier proposals for GitHub Pages plus a VPS are superseded as the launch plan. No public compiler server, cloud deployment, remote queue or packaged executable is currently provided.
